# 사원 · Sanctuary

말없이 함께 머무는 온라인 사원. 성당·교회·모스크·절 중 마음 가는 곳으로.

- `index.html` — 사원 선택 화면
- `common/` — 공통 엔진 (아바타·걷기·UI·소리·꾸미기·말풍선) `core.js` + `sanctuary.css`
- `cathedral/` — 성당 (미사 참례, 복사 체험, 성가대, 고해성사, 찰고, 초 봉헌)
- `church/` — 교회 (찬양대·청년·금요 철야 예배, 성찬식, 헌금 ATM, 주보, 새가족 등록, 통성기도, 성경 퀴즈)

직접 다녀온 곳만, 하나씩 문을 열어갑니다. 모스크·절 준비 중.
